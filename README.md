# Wander-App

Web-App für das jährliche Wanderwochenende der Truppe – zuerst für die
10. Jubiläumstour nach Mallorca (Serra de Tramuntana, 16.–20.09.2027).

Geplante Bausteine: Countdown und monatliche Reveals, Rätsel alle 14 Tage mit
Rangliste, Etappen, Teilnahme, Kasse, Packliste, Tagebuch, Hall of Fame mit
Tourarchiv, Orga-Kalender und Pool-Olympiade.

Technik: statische Web-App auf GitHub Pages, Daten und Logins über Supabase.
